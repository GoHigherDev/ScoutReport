# ScoutReport

A SportFi / SocialFi dapp on Chiliz Chain that adds utility on top of Socios.com Fan Tokens.

Work is tracked in Jira project **SR** (scoutreport.atlassian.net). Every branch, commit and pull request title must include its Jira key, e.g. `SR-2`, so it shows on the ticket.

The monorepo is scaffolded by ticket SR-2 ([F-01] Monorepo and app repo setup).
