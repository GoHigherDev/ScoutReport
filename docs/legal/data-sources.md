# Predict data sources — SR-41

**Draft, pending legal review. Not legal advice.**
This records permitted sources and review work, not licensing or legal approval.

| Data                                 | Source and limits                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fixture metadata and results         | Existing SR-44 admin-managed `matches` in Postgres. Operators verify the official football competition/club or CS2 tournament organiser's published result and record the official reference, following [settlement runbook](../runbooks/settlement.md). No new API, scraping or fabricated response is added. Provider licensing/reuse terms need review before adding a feed.                                                                                                                                                                            |
| Picks and signatures                 | Wallet's free EIP-712 message, to be verified and persisted by SR-45. No paid transaction or chain write. SR-41 adds storage/erasure infrastructure, not submission.                                                                                                                                                                                                                                                                                                                                                                                       |
| Prediction points                    | Existing SR-44 idempotent server scorer and `prediction_points`; derived from correct picks and fixture configuration. No external RP source or invented RP figures; points have no cash value and are non-transferable.                                                                                                                                                                                                                                                                                                                                   |
| Wallet identity and 18+ confirmation | Existing verified SIWE session and the wallet holder's explicit `confirmed: true` request. This is self-confirmation, not identity verification or evidence of date of birth.                                                                                                                                                                                                                                                                                                                                                                              |
| Terms acceptance                     | Session wallet, current server terms version, server UTC time and trusted platform country/result. No client identity/country field or raw IP storage.                                                                                                                                                                                                                                                                                                                                                                                                     |
| Country                              | Platform-overwritten [Vercel request headers](https://vercel.com/docs/headers/request-headers), specifically `x-vercel-ip-country`. Country-only resolution cannot distinguish Northern Ireland or sanctioned regions. Deployment must verify spoofing protection before exposure.                                                                                                                                                                                                                                                                         |
| Draft country restrictions           | Ticket's named countries plus a conservative whole-country screening seed in `predict-config.ts`, **for counsel to confirm**. Consult [UK financial sanctions regimes](https://www.gov.uk/government/collections/financial-sanctions-regime-specific-consolidated-lists-and-releases) and [OFAC sanctions programmes and country information](https://ofac.treasury.gov/sanctions-programs-and-country-information). These programmes include targeted/regional measures; the draft list is not a legal determination or complete person/entity screening. |
| Privacy screening                    | [ICO DPIA guidance](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/accountability-and-governance/data-protection-impact-assessments-dpias/) and [screening record](predict-dpia-screening.md). Counsel/controller confirm necessity, lawful bases and mitigations.                                                                                                                                                                                                                                                                    |

These are source references for the review checkpoint dated 14 October 2026,
not a claim that all external pages were independently verified on that date.
Record reviewer, review date, applicable geography, licence/terms evidence and
changes before enabling a new source. Do not store source page contents, raw
provider responses, raw IPs or credentials in audits. AppKit analytics remains
off and no additional third-party trackers or source integrations are added.
